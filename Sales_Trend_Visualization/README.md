# Sales Trend Visualization 📊

## Overview

Sales Trend Visualization is a Python-based data analysis project that helps analyze sales data and visualize product-wise sales performance. The project calculates key sales metrics and generates charts to provide insights into sales trends.

This project helps beginners learn data analysis, data visualization, CSV file handling, and Python libraries such as Pandas and Matplotlib.

## Features

* 📈 Total sales calculation
* 📊 Product-wise sales analysis
* 💰 Average sales calculation
* 🏆 Best-selling product identification
* 📉 Bar chart visualization
* 🥧 Pie chart visualization
* ⚡ Beginner-friendly Python project

## Technologies Used

* Python 3
* Pandas
* Matplotlib

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open Terminal.
5. Install required libraries:

```bash
pip install pandas matplotlib
```

6. Run the project:

```bash
python sales_analysis.py
```

## Dataset Columns

| Column  | Description  |
| ------- | ------------ |
| Product | Product name |
| Sales   | Sales amount |

## How It Works

1. Read sales data from a CSV file.
2. Calculate total sales.
3. Calculate average sales.
4. Group sales by product.
5. Identify the best-selling product.
6. Generate bar chart and pie chart visualizations.
7. Display results in the terminal.
